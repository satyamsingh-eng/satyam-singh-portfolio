## Key Architectural Principles

1. **Separability (Drag-and-Drop):** `SHRAVU - PORTFOLIO` is engineered as an entirely modular unit. If moved or decoupled in the future, `SATYAM PORTFOLIO` continues to function with zero broken dependencies.
2. **Strict Verification Standard:** Every scholarship, university, and competition claim is backed by primary source official links in respective project and research folders.
3. **Zero-Emoji Monochromatic Discipline:** Both resumes and web portfolios adhere to `#0b0b0b` / `#1d1d1f` / `#ffffff` / `#f5f5f5` typographic discipline without decorative emojis or colorful badges.
