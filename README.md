## 🛡️ Key Architectural Principles

1. **Separability (Drag-and-Drop):** `SHRAVU - PORTFOLIO` is engineered as an entirely modular unit. If moved or decoupled in the future, `SATYAM PORTFOLIO` continues to function with zero broken dependencies.
2. **Strict Verification Standard:** Every scholarship, university, and competition claim is backed by primary source official links in `00_MASTER_OPPORTUNITY_REGISTRY/`.
3. **Monochromatic Apple Swiss Design:** Both resumes and web portfolios adhere to `#000000` / `#1D1D1F` / `#F5F5F7` typographic discipline without rainbow gradients or superficial badges.
